# 云端接入

云端 TTS 通过 **`ziyu-cloud`** 独立模块接入，核心库 `ziyu` 保持零网络依赖。

```
前端（归一化文本） ─▶ CloudBackend ─▶ CloudTransport（发请求 + 解码） ─▶ PCM
```

## 1. 选型参考

| 服务 | 协议 | 免费额度 | 流式 | 备注 |
|---|---|---|---|---|
| **腾讯云** | REST + SSE | 最大（基础/精品 800 万字符） | ✅ | 主力，协议最省事 |
| Azure F0 | REST | 50 万字符/月（长期） | ✅ | 境外卡、并发 1 |
| 阿里云百炼 | REST + SSE | 无长期免费 | ✅ | 单请求上限 300 字符 |
| 讯飞 | WebSocket | 每日 500 次 | ✅ | 唯一离线商用路径（MSC SDK） |
| Edge TTS | 逆向接口 | 免费 | ✅ | 无授权无 SLA，仅原型 |

本项目实现腾讯云；其它服务按 `CloudTransport` 接口在独立模块接入。

## 2. 依赖：stdx（非 http_lib）

- ⚠️ 曾评估 `http_lib`，但其 TLS 依赖 `jinguissl_core` 使用 `@CallingConv[STDCALL]`，**在 Windows cjnative 无法编译**，故弃用。
- 改用官方 **`stdx.net.http`**（HTTP/1.1 + HTTP/2 客户端）+ `stdx.net.tls` + `stdx.crypto.digest` + `stdx.encoding.{json,base64,hex}`，全纯仓颉跨平台。
- 需 **stdx 1.2.0**，用 `cangjie-coding` 技能的 `setup_stdx.py --project <root>` 配置（离线可用 `--archive`/`--offline`）。

## 3. 腾讯云参数（经官方文档核实）

- **Action** = `TextToVoice`；**Version** = `2019-08-23`；**Host** = `tts.tencentcloudapi.com`
- **必填**：`Text`、`SessionId`
- **选填**：`ModelType` / `Volume` / `Speed`(`[-2,6]`) / `ProjectId` / `VoiceType` / `PrimaryLanguage`(1 中文/2 英文) / `SampleRate`(默认 16000) / `Codec`(`wav`/`mp3`/`pcm`) / `EnableSubtitle` 等
- **响应**：`Response.Audio` 为 base64；`Subtitles[]` 另含 `Phoneme` 音素

映射为 `TencentTtsConfig`：

```cangjie
import ziyu_cloud.{TencentCloudTransport, TencentTtsConfig}
import ziyu.backend.CloudBackend
import ziyu.Tts

let cfg = TencentTtsConfig(
    secretId, secretKey,               // 建议经环境变量注入
    region: "ap-guangzhou",
    codec: "pcm",                      // pcm 可直接转，规避 mp3 解码
    voiceType: 0, sampleRate: 16000
)
let tts = Tts(backend: CloudBackend(transport: TencentCloudTransport(cfg)))
let pcm = tts.speak("你好，欢迎使用仓颉编程语言。")
```

## 4. 鉴权：TC3-HMAC-SHA256

`src/tc3.cj` 实现腾讯云 TC3 签名（公开规范），纯 stdx：

1. 规范请求串 `CanonicalRequest`（method/uri/query/canonicalHeaders/signedHeaders/hash(payload)）
2. 待签串 `StringToSign`（`TC3-HMAC-SHA256` + 时间戳 + 凭据范围 + hash(CanonicalRequest)）
3. 签名 `Signature`（`HMAC(HMAC(HMAC("TC3"+key, date), service), "tc3_request")`）
4. `Authorization: TC3-HMAC-SHA256 Credential=..., SignedHeaders=..., Signature=...`

签名用 `stdx.crypto.digest.HMAC(key, HashType.SHA256)` + `stdx.encoding.hex.toHexString`，**无需 FFI**。UTC 日期由 `DateTime.nowUTC().toUnixTimeStamp()` 计算。

## 5. 关键约束与规避

- **文本上限 150 汉字** → `splitForCloud(text, 150)` 按句边界切分，逐段合成拼接（流式则逐段产出）
- **响应是 base64** → 解码后按 `codec` 转 PCM（`pcm16ToF32`；`wav` 跳 44 字节头）
- **Volume 口径** → 保守按 `[0,10]`，实测校准
- **多音字读错**（如腾讯云把「仓颉」读成 `cāng xié`）→ `CloudPronunciation` 发送前同音替换：
  ```cangjie
  let pron = CloudPronunciation()
  pron.add("仓颉", "仓杰")            // 读 cāng jié
  TencentCloudTransport(cfg, pronunciation: pron)
  ```

## 6. 运行示例

```powershell
$env:TENCENT_SECRET_ID="你的SecretId"
$env:TENCENT_SECRET_KEY="你的SecretKey"
cd ziyu/examples/cloud
cjpm run          # 生成 tencent_output.wav
```

无密钥时自动走 `MockTransport` 链路（跳过真实请求）。

## 7. 待补齐

- **SSE 真流式**：当前 `synthesizeStream` 为「分段流式」（整段接口逐段产出）；逐字 SSE 流式需接入对应 Action
- **`codec=mp3`**：需接 `audio4cj` 解码（当前支持 `pcm`/`wav`）
- **`Subtitles[].Phoneme`**：可解析以获取腾讯云注音，用作校验 ziyu 前端多音字/断句的免费参照
