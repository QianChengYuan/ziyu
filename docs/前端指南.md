# 前端指南 —— 中文文本前端

前端是 ziyu 的护城河：把原始文本变成合成引擎可直接消费的「音素序列 + 韵律」。
全程**纯仓颉、零 FFI、零外部依赖**。

```
原始文本 ─▶ 归一化 TN ─▶ 分词 ─▶ 音素转换（含儿化/轻声/韵律） ─▶ 变调 ─▶ FrontendResult
```

## 1. 一站式入口

```cangjie
import ziyu.frontend.DefaultFrontend
import ziyu.frontend.FrontendResult

let fe: FrontendResult = DefaultFrontend().process("你好，欢迎使用仓颉编程语言。", "zh-CN")
```

`FrontendResult`（`src/frontend/frontend.cj`）：

| 字段 / 方法 | 说明 |
|---|---|
| `text: String` | 归一化后文本 |
| `language: String` | 语言标识（如 `"zh-CN"`） |
| `phonemes: Array<Phoneme>` | 音素序列（含韵律） |
| `symbols(): Array<String>` | 便捷：仅取音素符号序列 |
| `isEmpty(): Bool` | 是否无音素 |

`Phoneme`：`symbol: String`（带调拼音数字调，如 `"ni3"`）+ `pauseAfterMs: Int64`（其后停顿）。

## 2. 文本归一化 TN（§3.1）

`normalizer.cj` 在分词前把数字符号展开为中文读法，避免「3.5 元」被念错。

| 输入 | 输出 |
|---|---|
| `订单号2026，共3.5元。` | 订单号二千零二十六，共三点五元。 |
| `发布日2026/10/21，折扣50%。` | 发布日二零二六年十月二十一日，折扣百分之五十。 |
| `电话13800138000，订1/2份。` | 电话一三八零零一三八零零零，订二分之一份。 |
| `总价¥1999，质保2年。` | 总价一千九百九十九元，质保二年。 |
| `编号100001，共120人，第10名。` | 编号十万零一，共一百二十人，第十名。 |

覆盖：数量 / 年份 / 小数 / 日期（`YYYY/MM/DD`、`YYYY-MM-DD`）/ 金额（`¥ $ ￥`）/ 分数 / 百分号 / 电话（逐位）。
中文单位形式（`2026年10月21日`）由分词天然分段，无需特殊处理。

直接调用归一化：

```cangjie
import ziyu.frontend.DefaultNormalizer
let norm = DefaultNormalizer().normalize("共3.5元", "zh-CN")  // 共三点五元
```

## 3. 分词与音素

- 中文按字、英文按词、数字与标点独立成 token（`tokenizer.cj`）
- 音素转换（`phonemizer.cj`）：查 20903 条词典（复刻自 pinyin4cj，MIT），带调符号转数字调（`nǐ`→`ni3`）
- 未收录字原样保留；标点 / 空白跳过并转成韵律停顿（逗号 200ms、句号 400ms）

**解析循环同时产出音素与韵律**，因此「多 token → 少音素」的映射（多音字词组、儿化合并）下停顿仍与音素正确对齐。

## 4. 多音字消歧（§3.3）

`polyphone.cj` 的 `PolyphoneResolver` 做**最长词组匹配**，未命中回退单字默认读音（词典首读）。

```
银行行长在重庆 → yin2 hang2 · hang2 zhang3 · zai4 · chong2 qing4
```

用户扩展（可覆盖）：

```cangjie
import ziyu.frontend.DictionaryPhonemizer
import ziyu.frontend.DefaultFrontend

let ph = DictionaryPhonemizer()
ph.addWord("奇点", ["qi2", "dian3"])         // 逐字带调数字调
let fe = DefaultFrontend(phonemizer: ph).process("奇点", "zh-CN")
```

## 5. 变调（§3.4）

`applyToneSandhiByPauses` 在 pipeline 阶段**按停顿分段**应用变调（标点阻断变调链）：

- **一 / 不**：一 + 去声 → 阳平（`yi2`）；一 + 阴/阳/上声 → 去声（`yi4`）；不 + 去声 → 阳平（`bu2`）
- **三声连读**：上声 + 上声 → 前一个变阳平

```
一个不好的一定     → yi2 ge4 · bu4 hao3 · de5 · yi2 ding4
你好我也想买水果   → ni2 hao2 wo2 ye2 xiang2 mai2 shui2 guo3   （无停顿，链式变调）
你好，我也想买水果 → ni2 hao3 wo2 ye2 xiang2 mai2 shui2 guo3   （逗号阻断，"好"保留三声）
```

## 6. 儿化音与语气词轻声（§3.4）

- **儿化**：汉字 + 「儿」（且儿后非「子」）合并为一个儿化音节，韵母追加 `r`（后端剥离 `r` 按原韵母合成）
  ```
  这是花儿吗 → zhe4 shi4 hua1r ma5
  你去哪儿啊 → ni3 qu4 na3r a5
  儿子在家   → er2 zi5 zai4 jia1     （"儿子"不儿化）
  ```
- **语气词轻声**：句末语气词（吗/呢/吧/啊/呀/…）按字形强制轻声
- 内置常见轻声词（儿子/我们/朋友/东西…）

## 7. 接口与扩展点

| 接口 | 实现 | 方法 |
|---|---|---|
| `TextNormalizer` | `DefaultNormalizer` | `normalize(text, language): String` |
| `Tokenizer` | `MixedTokenizer` | `tokenize(text): Array<Token>` |
| `Phonemizer` | `DictionaryPhonemizer` | `toPhonemes(tokens, language): Array<Phoneme>` |
| `TextFrontend` | `DefaultFrontend` | `process(text, language): FrontendResult` |

自定义任意环节后注入：

```cangjie
let fe = DefaultFrontend(
    normalizer: myNormalizer,
    tokenizer: myTokenizer,
    phonemizer: myPhonemizer
)
```

> ⚠️ 未覆盖或多音字：`PolyphoneResolver.addWord` 与 `DictionaryPhonemizer.addWord` 可随时补充专名读音。
