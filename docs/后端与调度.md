# 后端与调度

`ziyu.Tts` 是用户 API 门面，把「文本前端」与「可替换的 backend」串起来。

```
文本 ──▶ Tts.speak / speakStream ──▶ 前端 process() ──▶ TtsBackend ──▶ PCM
```

## 1. Tts 门面

```cangjie
import ziyu.Tts

let tts = Tts()                                       // 默认：DefaultFrontend + LocalBackend
let pcm = tts.speak("你好，欢迎使用仓颉编程语言。")     // 整段 AudioBuffer
let stream = tts.speakStream("…", language: "zh-CN")  // 流式 AudioStream
let cap = tts.capabilities()                          // 当前后端能力
```

| 方法 | 说明 |
|---|---|
| `speak(text, language = "zh-CN"): AudioBuffer` | 整段合成 |
| `speakStream(text, language = "zh-CN"): AudioStream` | 流式合成（逐块 PCM） |
| `capabilities(): BackendCapability` | 后端能力声明 |

注入自定义前端 / 后端：

```cangjie
let tts = Tts(frontend: DefaultFrontend(), backend: LocalBackend())
```

## 2. TtsBackend 接口

`src/backend/backend.cj`：

```cangjie
public interface TtsBackend {
    func synthesize(input: FrontendResult): AudioBuffer
    func synthesizeStream(input: FrontendResult): AudioStream
    func capabilities(): BackendCapability
}
```

`BackendCapability`：`name` / `languages` / `sampleRate` / `channels` / `streaming` / `offline` / `native`。

`AudioStream`：逐块产出 PCM（封装 `ziyu.core.SynthesisStream` 阻塞队列）；`nextChunk(): ?AudioBuffer`（`None` 表示结束）、`tryNextChunk()`。

## 3. LocalBackend（本地共振峰）

`src/backend/local.cj` 包装 `FormantSynthesizer`，纯仓颉、离线、单声道 22050Hz。

```cangjie
import ziyu.backend.LocalBackend
import ziyu.core.{SynthesisOptions, Voice, VoiceGender}

let backend = LocalBackend(
    voice: Voice("zh-CN-local", "zh-CN", 22050, VoiceGender.Neutral),
    options: SynthesisOptions(1.0, 1.0, 1.0)   // speed / pitch / volume
)
let tts = Tts(backend: backend)
```

`capabilities()`：`name="local-formant"`、`offline=true`、`native=false`。

底层 `ziyu.synth.FormantSynthesizer` 实现 `SynthesisEngine`（`synthesize(request)` / `synthesizeStream(request)`），并额外提供按音素序列合成入口 `synthesizePhonemes` / `streamPhonemes`，供 backend 直接消费前端产出（避免重复前端处理）。

## 3.5 SystemBackend（系统 TTS）—— Windows SAPI

`src/backend/system.cj` 调用操作系统内置语音合成，**零 FFI**：经 `std.process` 运行 PowerShell 的 `System.Speech` 把文本合成到 WAV，再读回解析为 PCM。

```cangjie
import ziyu.backend.SystemBackend
let tts = Tts(backend: SystemBackend(voiceName: "Microsoft Huihui Desktop"))
```

`capabilities()`：`name="system-sapi"`、`offline=true`、`native=false`（进程调用而非 native 绑定）。
平台：Windows（`System.Speech` 自带；中文需已装中文语音，如 `Microsoft Huihui Desktop`）。

## 3.6 EspeakBackend（espeak-ng）—— 跨平台命令行

`src/backend/espeak.cj` 经 `std.process` 调用 `espeak-ng` 合成到 WAV，再读回解析为 PCM（**零 FFI**，Windows / Linux / macOS 通用）。

```cangjie
import ziyu.backend.EspeakBackend
let be = EspeakBackend(voice: "cmn")        // cmn=官话；另有 en-us 等
if (be.isAvailable()) {
    let tts = Tts(backend: be)
    let pcm = tts.speak("你好，欢迎使用仓颉编程语言。")
}
```

`capabilities()`：`name="espeak-ng"`、`offline=true`、`native=false`。
依赖：系统需安装 `espeak-ng`（含中文语音数据）；`isAvailable()` 可预检。

## 4. CloudBackend（云端）

`src/backend/cloud.cj` 通过**传输层依赖注入**把网络与解码隔离在核心库之外：

```cangjie
public interface CloudTransport {
    func synthesize(request: CloudRequest): AudioBuffer
    func synthesizeStream(request: CloudRequest): AudioStream
}
```

`CloudBackend` 负责构造 `CloudRequest`（归一化文本 + 参数）、调度传输层、声明能力：

```cangjie
let backend = CloudBackend(
    transport: myTransport,          // 真实云端实现（见《云端接入》）
    voiceId: "zh-CN-Xiaoxiao",
    language: "zh-CN",
    sampleRate: 24000
)
let tts = Tts(backend: backend)
```

`LoopbackTransport`：本地回环实现（用 `LocalBackend` 模拟云端），无需网络即可验证调度链路。

## 5. 自定义 Backend

实现 `TtsBackend` 即可接入任意引擎（系统 TTS / ONNX / 其它云）：

```cangjie
import ziyu.backend.{AudioStream, BackendCapability, TtsBackend}
import ziyu.frontend.FrontendResult
import audio4cj.pcm.AudioBuffer

public class MyBackend <: TtsBackend {
    public func synthesize(input: FrontendResult): AudioBuffer {
        // input.symbols() 取音素序列；或 input.text 取归一化文本
        MyEngine.synth(input.text)
    }
    public func synthesizeStream(input: FrontendResult): AudioStream {
        MyEngine.synthStream(input.text)
    }
    public func capabilities(): BackendCapability {
        BackendCapability(name: "my", languages: ["zh-CN"], sampleRate: 24000,
            channels: 1, streaming: true, offline: false, native: false)
    }
}
```

> 约定：吃**音素 + 韵律**的引擎（本地 ONNX）用 `input.symbols()`；只吃**文本**的引擎（系统 / 云端）用 `input.text`。

## 6. 流式播放（ziyu-play）

合成与播放解耦：`ziyu-play` 模块的 `ZiyuPlayer` 阻塞拉取 `SynthesisStream` 并喂入 `play4cj` 的 `PcmSink`，实现「边合成边播放」。

```cangjie
import play4cj.winsound.WaveOutStreamSink
import ziyu_play.ZiyuPlayer

let player = ZiyuPlayer(WaveOutStreamSink())
let total = player.play(stream, sampleRate, 1)
```

完整示例见 `examples/play`。
